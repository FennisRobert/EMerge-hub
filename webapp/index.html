EMerge Template Explorer

A browsable library of EMerge simulation templates: antennas, filters, dividers, couplers, and more. Each entry has a rendered geometry preview, a technical description, and the full Python source behind it.

How to use this page

  1. Browse the categories on the left. Click a section title to expand or collapse it, or use the search box to jump straight to a template.
  2. Select a template to see its geometry preview, target application, and complete source code.
  3. If a template has both a v2.8 and v3.0 version, switch between them with the tabs above the code panel.
  4. Click the copy icon to copy the script, then paste it into a local Python environment with EMerge installed and run it there. The simulations need a real Python interpreter and solver, so nothing here runs inside the browser.
